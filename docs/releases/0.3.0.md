# 拾音 0.3.0 / Shiyin 0.3.0

## 下载和运行 / Download and run

下载 **Shiyin-0.3.0-windows-x64.zip**，完整解压后运行 **Shiyin/Shiyin.exe**。保留旁边的 `vlc/` 目录。支持 Windows 10/11 x64，无需安装 Python、Rust 或 VLC；可执行文件静态链接 MSVC C 运行库，无需单独安装 VC Redistributable。

Download **Shiyin-0.3.0-windows-x64.zip**, extract everything and run **Shiyin/Shiyin.exe**. Keep the adjacent `vlc/` directory. Windows 10/11 x64; no Python, Rust, VLC or separate VC Redistributable installation required.

`*.sha256` 用于完整性校验。`verification.json` 是打包后的播放自检报告。`third-party-sources.zip` 是第三方源码材料，普通用户无需下载。GitHub 自动生成的 Source code 附件是项目源码，不是可执行包。

SHA-256 files verify integrity; verification.json records packaged playback checks. The third-party source archive is optional for end users. GitHub's automatic Source code archives are not the Windows executable bundle.

## 更新 / Changes

- Rust 成为主项目，Python 仅保留源码、测试和构建脚本备份，共用主项目文档。
- 多目录音乐库、标签乱码恢复、文件名回退和自定义显示名称。
- 多关键字、短语、排除、OR 和通配符搜索。
- 默认与自建歌单，一首歌曲可加入多个歌单，共享收藏和名称。
- 暂停继续、连续切歌、列表/单曲循环、随机播放，点击或拖动进度和音量。
- 中英文界面、关闭策略、系统托盘和播放菜单；布局与字体保持紧凑。
- 异步扫描、取消、安全退出、原子保存、单实例锁和重启恢复；不使用工作子进程。

Rust is now the main implementation. Includes multi-folder libraries, metadata repair, flexible search, shared playlist membership, repeat/shuffle playback, click-to-seek, bilingual UI, tray controls and durable state restoration.

## 升级 / Upgrade

先退出旧播放器，再运行新版。安装版配置仍使用 `%LOCALAPPDATA%\Shiyin`；建议先备份 library.json。旧源码版或 Rust 预览版配置可通过“管理目录 → 导入曲库配置”导入；导入替换当前配置并备份目标，不自动合并。音乐文件无需移动，不会被改名或改写。

Exit the old player first. Installed settings remain in `%LOCALAPPDATA%\Shiyin`; back up library.json before upgrading. Import older source/preview settings through Manage folders → Import library settings. Import replaces current state with a backup; it does not merge. Music files remain untouched.

## 验证与已知边界 / Verification and limits

本机已通过 9 项逻辑/持久化测试、10 分钟播放、120 次连续切歌、扫描中退出、三次重启以及托盘和界面回归。发布流程重新检查格式、Clippy、测试，并运行可执行包的原生播放自检。持续数小时、其他声卡及跨屏 DPI 仍需进一步验证。无代码签名；不包含手机同步功能。

Local checks cover nine tests, a 600-second playback run, 120 rapid skips, exit during scanning, three restarts and GUI/tray regression. Release CI repeats formatting, Clippy, tests and packaged native playback verification. Multi-hour sessions, other audio devices and cross-monitor DPI need more testing. Unsigned; mobile sync is not included.
