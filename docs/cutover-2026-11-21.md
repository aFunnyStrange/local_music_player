Rust promoted to repository root; Python archived in backup/python. Version 0.3.0, executable Shiyin.exe. No GitHub Release was published.

沿用 %LOCALAPPDATA%\Shiyin 配置；切换前安装版和预览版 JSON、旧快捷方式备份在本机忽略目录 .runtime/cutover-2026-11-21。源码版 data/ 随 Python 归档。预览版 ShiyinRust 配置保持原样，没有自动合并。音乐路径和音乐文件不移动。

Reuses installed settings after local backups; preview settings remain untouched and are not merged. Music files and paths are unchanged.

Formatting, Clippy and nine tests passed. Bundled native playback passed with restricted PATH. A fresh 30-second run passed 120 skips and 20 pause/resume pairs. Python 备份随后精简为源码、测试、资源及构建工具链脚本，重复文档和本机旧产物移至 Git 忽略的 .runtime/retired-python；旧 rust-player 目录仅含编辑器缓存，已从项目根移走。主项目文档由旧构建脚本共享读取。

发布版通过 .cargo/config.toml 静态链接 MSVC C 运行库，导入表已确认无 VCRUNTIME140.dll 依赖；检查 370 个可执行文件/动态库的导入，没有发现未解析依赖。GitHub 应用 Release 与 crates.io 包发布无关，Cargo.toml 保持 publish=false。

Source-only Python backup now shares main documentation. Old generated files remain outside the source tree in ignored local storage. Release builds link the MSVC C runtime statically; no VCRUNTIME140.dll import remains. Dependency inspection found no unresolved imports across 370 PE files. This is a GitHub application Release, not a crates.io publication; publish=false is intentional.
